# Qubettera

Qubettera retrieves evidence from a local MiniLM/PostgreSQL knowledge base,
then gives that evidence to persona agents whose answers are generated by an
Ollama-compatible model running in a Kaggle notebook. Agents exchange their
opinions over a strongly connected graph and persist the complete discussion.

```text
question -> MiniLM + hybrid PostgreSQL retrieval -> cited evidence
         -> Kaggle generation model -> multi-agent rounds -> saved history
```

## Setup

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
Copy-Item .env.example .env
docker compose up -d
qubettera doctor
```

Set `KAGGLE_LLM_URL` and `KAGGLE_LLM_MODEL` in `.env` to match the notebook.
MiniLM is used only for embeddings and retrieval; Kaggle generates answers.

## Commands

```powershell
qubettera rag pipeline --skip-collection
qubettera rag retrieve "mixture of experts routing" --top-k 5
qubettera rag evaluate
qubettera agent opinion dr_aris "Dense versus sparse transformer layers"
qubettera discuss run --mode fake
qubettera discuss run --mode live
```

Generated corpus files live in `data/`; opinions and discussions live in
`outputs/`. Architecture notes and the former coursework documentation are in
`docs/`.
